# Windows 10/11 Compatibility

This directory contains the ICC profiles which are installed by the [original installer of DCS Custom Looks 2.0](https://github.com/puinhoop/Kodak-DCS-Software-Archive/tree/main/windows-software/custom-looks/2.0/original).

You can use this if you prefer to manually install DCS Custom Looks 2.0 on Windows 10/11 instead of using the original installer in compatibility mode for Windows XP (Service Pack 3).


## Installation

Each ZIP file contains 10 ICM files. Version 1.0 of the ICC profiles is only required if you are using Capture Studio 1.7. Hence, you only need to install version 2.0 of the ICC profiles if you are using [Photo Desk 4.3](https://github.com/puinhoop/Kodak-DCS-Software-Archive/tree/main/windows-software/photo-desk/4.3/original).

1. Download [CustomLooks_ICC_Profiles_2.0.zip](https://github.com/puinhoop/Kodak-DCS-Software-Archive/blob/main/windows-software/custom-looks/2.0/compatibility/windows-10-11/CustomLooks_ICC_Profiles_2.0.zip)

2. Extract `CustomLooks_ICC_Profiles_2.0.zip` and copy the extracted ICM files to the following directory:

   `C:\Windows\System32\spool\drivers\color`

## Tested

- Windows 10 x64
- Windows 11 x64
